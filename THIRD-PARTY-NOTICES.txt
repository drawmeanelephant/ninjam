Third-party notices for the NINJAM revival distribution
=======================================================

This distribution ships two executables built from this repository:

  ninjamsrv      the NINJAM server
  ninjam-client  the GUI jam client

The NINJAM code itself is licensed under the GNU GPL v2 or later; see the
LICENSE file shipped alongside this one. The third-party components below are
linked into the executables named in each section and carry the license texts
reproduced in full, unmodified, from the pinned upstream revisions.

Where a component is fetched at configure time (CMake FetchContent), the "Pin"
line records the exact upstream revision pinned in this release's build files.
tools/check_release_notices.py runs during release packaging and fails the
build if any notice goes missing or a pin recorded here drifts from the build
files. WDL and JNetLib are vendored in-tree under WDL/; their license text
lives in the source file headers, from which it is reproduced below.
